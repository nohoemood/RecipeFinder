# RecipeFinder

Recipe finder for iOS built with UIKit and GCD. Search meals by ingredient, cuisine or category, powered by [TheMealDB API](https://www.themealdb.com/api.php).

No API key setup required - the app uses TheMealDB public test key.

## Features
- Search meals by name or ingredient
- Browse by cuisine and category
- Recipe details with ingredients and instructions

## Design
Designed in Figma before development. View [Figma Mockup]([https://www.themealdb.com/api.php](https://www.figma.com/design/L4A4oO9UULrnfHyGhVuXXU/Recipe-search--Mobile-App-?node-id=0-1&t=VZ7DMFXzCRB4sGuI-1)).

## Stack
- Swift
- UIKit
- MVVM + C with Clean Architecture
- GCD
- URLSession + Codable

## Getting started
1. Clone the repo: `git clone https://github.com/nohoemood/RecipeFinder.git`
2. Open `RecipeSearch.xcodeproj` in Xcode
3. Build & run (⌘R)
