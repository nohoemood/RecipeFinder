# RecipeFinder
Recipe finder for iOS built with UIKit and GCD. Search meals by ingredient, cuisine or category, powered by [TheMealDB API](https://www.themealdb.com/api.php).

No API key setup required - the app uses TheMealDB public test key.

## Features
1. Search meals by name or ingredient
2. Browse by cuisine and category
3. Recipe details with ingredients and instructions

## Design
Designed in Figma before development. [View Figma Mockup](https://www.figma.com/design/L4A4oO9UULrnfHyGhVuXXU/Recipe-Finder--Mobile-App-?node-id=0-1&t=VZ7DMFXzCRB4sGuI-1)

## Stack
1. Swift
2. UIKit
3. MVVM + C with Clean Architecture
4. GCD
5. URLSession + Codable

## Getting started
1. Clone the repo: `git clone https://github.com/nohoemood/RecipeFinder.git`
2. Open `RecipeSearch.xcodeproj` in Xcode
3. Build & run (⌘R)
